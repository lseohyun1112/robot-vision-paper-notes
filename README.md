# Robot Vision Paper Notes

로봇 비전 AI를 기초부터 공부하기 위한 주간 논문 노트 저장소입니다.

매주 월요일에 다음 내용을 담은 Markdown 노트가 `papers/YYYY/MM/` 아래에 추가됩니다.

- 이번 주 주제와 논문 선정 이유
- 선수지식과 핵심 용어
- 핵심 논문 및 선택 논문 링크
- 논문 요약과 중요 그림·표·수식
- 읽으며 답할 질문
- 2~3시간 학습 계획
- 작은 실습 또는 재현 과제

전체 목록은 [논문 인덱스](papers/README.md)에서 확인할 수 있습니다.

## 공개 저장소 원칙

이 저장소에는 공개 배포 가능한 학습 노트만 기록합니다.

- 논문은 원문 링크와 직접 작성한 요약만 사용합니다.
- 논문 PDF, 논문 그림 원본, 비공개 자료는 커밋하지 않습니다.
- API 키, 토큰, 비밀번호, 개인 연락처, 로컬 절대경로를 기록하지 않습니다.
- 자동화는 해당 주의 노트와 인덱스 등 명시된 파일만 커밋합니다.

자세한 점검 기준은 [공개 전 점검표](PUBLICATION_SAFETY.md)를 참고하세요.
